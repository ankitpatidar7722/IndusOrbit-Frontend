Set up your AI Summary keyअपनी AI Summary key सेट करें

Add your own free Google Gemini key so the Tracker's Summarize with AI button works for you. It takes about two minutes, and you only do it once.अपनी खुद की मुफ़्त Google Gemini key जोड़ें ताकि Tracker का Summarize with AI बटन आपके लिए चले। सिर्फ़ दो मिनट लगते हैं, और एक ही बार करना है।

Every user adds their own key, so no one ever hits a shared limit. Your key is free and stays private to your account.हर user अपनी अलग key डालता है, इसलिए किसी को limit की दिक्कत नहीं आती। Key बिलकुल मुफ़्त है और सिर्फ़ आपके account के लिए रहती है।
On GoogleGoogle पर

Get your free Gemini keyअपनी मुफ़्त Gemini key लें

From Google AI Studio — sign in with your office Google account.Google AI Studio से — अपनी ऑफिस Google account से sign in करें।
  1. 1
    Open Google AI StudioGoogle AI Studio खोलें

    Go to aistudio.google.com/apikey and sign in with your office Google account. You'll see the API Keys page with a Create API key button at the top-right.aistudio.google.com/apikey पर जाएँ और अपनी ऑफिस Google account से sign in करें। API Keys page खुलेगा, जिसमें ऊपर दाईं ओर Create API key बटन होगा।

  2. 2
    Create the API keyAPI key बनाएँ

    Click Create API key. Give it a name (e.g. IndusOrbit), keep the default project, and click Create key. It's on Google's free tier — no card, no cost.Create API key पर click करें। कोई नाम दें (जैसे IndusOrbit), default project रहने दें, और Create key दबाएँ। यह Google के free tier पर है — न card, न कोई cost।

  3. 3
    Copy your keyअपनी key copy करें

    A dialog shows your new key. Click Copy key. Keep it safe and don't share it with anyone.एक dialog में आपकी नई key दिखेगी। Copy key दबाएँ। इसे safe रखें और किसी के साथ share न करें।

In Indus Command CenterIndus Command Center में

Add the key to your profileKey को अपनी profile में जोड़ें

One-time — Settings keeps it saved for you.एक ही बार — Settings इसे saved रखता है।
  1. 1
    Open SettingsSettings खोलें

    Click your profile photo at the top-right, then Settings. On the Profile tab, scroll to the AI Summary Key (Gemini) section.ऊपर दाईं ओर अपनी profile photo पर click करें, फिर Settings। Profile tab में AI Summary Key (Gemini) section तक scroll करें।

  2. 2
    Paste your key and Saveअपनी key paste करके Save करें

    Click Add key (or Change), paste your key into the box, and click Save. A green ✓ Key configured confirms you're done.Add key (या Change) दबाएँ, अपनी key box में paste करें, और Save दबाएँ। हरा ✓ Key configured दिखते ही हो गया।

Now use itअब इस्तेमाल करें

Open any Tracker tab, create or edit a row, fill in the details, then click Summarize with AI. Your summary appears in the Summary field — fully editable.किसी भी Tracker tab में row बनाएँ/edit करें, details भरें, फिर Summarize with AI दबाएँ। Summary अपने आप Summary field में भर जाएगी — edit भी कर सकते हैं।

Good to knowजानने योग्य

It's freeमुफ़्त है

Google's free tier is plenty for tracker summaries — no card, no charges.Google का free tier tracker summaries के लिए काफ़ी है — न card, न charge।

Only yoursसिर्फ़ आपकी

Your key is tied to your account and never shown to anyone — only a masked value.Key सिर्फ़ आपके account से जुड़ी है और किसी को नहीं दिखती — बस masked।

Just onceएक ही बार

Set it a single time. Every future summary uses it automatically.एक बार set करें। आगे हर summary अपने आप इसी से चलेगी।

Change anytimeकभी भी बदलें

Settings → AI Summary Key → Change or Remove whenever you like.Settings → AI Summary Key → जब चाहें Change या Remove करें।

Trouble?दिक्कत?  “API key not valid” → re-copy the key from Google AI Studio (no extra spaces). No summary appears → make sure you filled in some row details first, then click Summarize again.  “API key not valid” → key को Google AI Studio से दोबारा copy करें (कोई extra space न हो)। Summary न आए → पहले row में कुछ details भरें, फिर दोबारा Summarize दबाएँ।
