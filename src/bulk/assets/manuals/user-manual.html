Chapter 1अध्याय 1

Login & Authenticationलॉगिन और प्रमाणीकरण

ExcelJet uses a two-step login process. First select your company, then enter your username and password.ExcelJet में दो-चरण लॉगिन प्रक्रिया होती है। पहले अपनी कंपनी चुनें, फिर यूज़रनेम और पासवर्ड डालें।

Step 1 — Select Your Companyचरण 1 — अपनी कंपनी चुनें

  1. Open your browser and go to the application URL given by your administrator.ब्राउज़र खोलें और अपने एडमिन द्वारा दिया गया एप्लिकेशन URL खोलें।

  2. On the Company Login screen, click the Select Company dropdown and choose your company.Company Login स्क्रीन पर Select Company ड्रॉपडाउन पर क्लिक करें और अपनी कंपनी चुनें।

  3. Click Login to proceed.Login बटन दबाएं।

Noteध्यान दें
If your company name does not appear in the list, contact your system administrator. The company must be registered before you can log in. अगर आपकी कंपनी का नाम लिस्ट में नहीं दिखे, तो अपने सिस्टम एडमिन से संपर्क करें।

Step 2 — Enter Your Credentialsचरण 2 — अपनी जानकारी दर्ज करें

  1. Enter your Username.अपना Username दर्ज करें।

  2. Enter your Password.अपना Password दर्ज करें।

  3. Click Sign In.Sign In बटन दबाएं।

Importantमहत्वपूर्ण
Passwords are case-sensitive. Ensure Caps Lock is OFF. If you fail multiple times, contact your administrator to reset your password. पासवर्ड case-sensitive होता है। Caps Lock बंद रखें। कई बार गलत पासवर्ड डालने पर एडमिन से पासवर्ड रीसेट कराएं।

Logging Outलॉगआउट करना

  1. Click your username/profile icon in the top-right corner.स्क्रीन के ऊपर-दाईं ओर अपने प्रोफ़ाइल आइकन पर क्लिक करें।

  2. A dropdown appears. Click Logout (shown in red at the bottom).ड्रॉपडाउन में नीचे Logout पर क्लिक करें।

  3. A confirmation dialog asks "Do you want to logout?" — Click Yes.एक confirmation dialog आएगा — Yes पर क्लिक करें।

Best Practiceअच्छी आदत
Always log out when you finish your session, especially on shared computers. काम खत्म होने पर हमेशा लॉगआउट करें, खासकर shared कंप्यूटर पर।

Chapter 4अध्याय 4

Import Masterइम्पोर्ट मास्टर

Import Master manages all master data — Ledger Master, Item Masters, Product Group Master, Spare Part Master, and Tool Master. All five modules use the same six-button interface.Import Master सभी मास्टर डेटा को manage करता है — Ledger Master, Item Masters, Product Group Master, Spare Part Master और Tool Master। पाँचों मॉड्यूल में एक जैसे छह बटन होते हैं।

Getting Startedशुरुआत कैसे करें

  1. Click Import Master in the left sidebar.बाईं साइडबार में Import Master पर क्लिक करें।

  2. Click the Module Name dropdown and select the master type (e.g., "Ledger Master", "Item Masters").Module Name ड्रॉपडाउन में मास्टर प्रकार चुनें (जैसे "Ledger Master", "Item Masters")।

  3. A second dropdown appears for the Group (e.g., Ledger Group). Select the specific group.Group के लिए दूसरा ड्रॉपडाउन दिखेगा (जैसे Ledger Group)। उचित group चुनें।

  4. Six action buttons appear. Choose the button matching what you want to do (see table below).छह एक्शन बटन दिखेंगे। आप जो करना चाहते हैं उसके अनुसार बटन चुनें (नीचे तालिका देखें)।

Refresh ButtonRefresh बटन
The purple ⟳ Refresh button resets the entire page — clears your selection, empties the grid. बैंगनी ⟳ Refresh बटन पूरे पेज को रीसेट कर देता है — चयन और ग्रिड दोनों खाली हो जाते हैं।

Workflow A — Viewing & Managing Existing RecordsWorkflow A — मौजूदा रिकॉर्ड देखना और प्रबंधित करना

  1. Select Module and Group, then click Load Data.Module और Group चुनें, फिर Load Data पर क्लिक करें।

  2. Grid loads all existing records. Header shows "Database Records (N rows)".ग्रिड में सभी मौजूदा रिकॉर्ड लोड होते हैं। हेडर में "Database Records (N rows)" दिखता है।

  3. To delete specific rows: tick the checkboxes on the left of those rows. The Soft Delete (N) button appears. Click it to delete permanently.खास rows हटाने के लिए: उनके बाईं ओर के checkbox पर टिक करें। Soft Delete (N) बटन दिखेगा। उस पर क्लिक करें — रिकॉर्ड स्थायी रूप से हट जाएंगे।

  4. To export: click Export to download as Excel.Export के लिए: Export पर क्लिक करें।

Soft Delete is PermanentSoft Delete स्थायी है
Soft Delete removes selected records from the database permanently. There is no undo. Select rows carefully. Soft Delete चुनी हुई rows को डेटाबेस से स्थायी रूप से हटा देता है। इसे वापस नहीं किया जा सकता। rows ध्यान से चुनें।

Workflow B — Existing Upload (Add Records)Workflow B — Existing Upload (रिकॉर्ड जोड़ना)

  1. Select Module and Group.Module और Group चुनें।

  2. Click Existing Upload. A file picker opens.Existing Upload पर क्लिक करें। File picker खुलेगा।

  3. Select your .xlsx file. The filename must match the group name exactly (e.g., Clients.xlsx for the "Clients" Ledger Group).अपनी .xlsx फ़ाइल चुनें। फ़ाइल का नाम group के नाम से बिल्कुल मेल खाना चाहिए (जैसे "Clients" group के लिए Clients.xlsx)।

  4. Grid loads and shows your Excel data as "Excel Preview".ग्रिड में आपका Excel डेटा "Excel Preview" के रूप में दिखेगा।

  5. Review the data. You can click any cell to edit it directly.डेटा देखें। किसी भी cell पर क्लिक करके उसे ग्रिड में ही edit किया जा सकता है।

  6. Click Check Validation. The system checks every row for errors.Check Validation पर क्लिक करें। सिस्टम हर row की जांच करेगा।

  7. A Validation Summary appears with coloured count cards. Click any card to filter the grid to show only those rows.Validation Summary में रंगीन count cards दिखेंगे। किसी भी card पर क्लिक करें — ग्रिड सिर्फ वही rows दिखाएगा।

  8. When all rows are valid, a pulsing Save Data button appears. Click it to save records to the database.जब सभी rows valid हों, एक चमकता Save Data बटन दिखेगा। उस पर क्लिक करें — रिकॉर्ड डेटाबेस में सेव हो जाएंगे।

Fix Errors Before SavingSave से पहले गलतियां सुधारें
The Save Data button only appears when ALL rows pass validation. Fix Duplicate, Missing, or Invalid rows in the grid or in your Excel file (re-upload). Save Data बटन तभी दिखेगा जब सभी rows validation pass करें। Duplicate, Missing या Invalid rows को ग्रिड में सुधारें या Excel में ठीक करके फिर से अपलोड करें।

  1. Select Module and Group.Module और Group चुनें।

  5. CAPTCHA 3/3: Solve and click Next.CAPTCHA 3/3: हल करें और Next पर क्लिक करें।

Stock Uploadस्टॉक अपलोड

Stock Upload lets you enter opening stock quantities for items, tools, and spare parts via Excel or direct grid entry.Stock Upload से आप Items, Tools और Spare Parts की प्रारंभिक स्टॉक मात्रा Excel या ग्रिड में सीधे दर्ज कर सकते हैं।

Getting Startedशुरुआत

  1. Click Stock Upload in the left sidebar.बाईं साइडबार में Stock Upload पर क्लिक करें।

  2. Select from Module Name: Item Masters, Tool Master, or Spare Part Master.Module Name में से चुनें: Item Masters, Tool Master या Spare Part Master।

ERP Transaction DeleteERP ट्रांजेक्शन डिलीट

Critical Warning — Permanent Deletionमहत्वपूर्ण चेतावनी — स्थायी विलोपन
All actions here permanently delete data. Deleted data cannot be recovered. Only authorised administrators should use this module. यहाँ सभी कार्य डेटा को स्थायी रूप से हटाते हैं। हटाया गया डेटा वापस नहीं आ सकता। केवल अधिकृत एडमिन ही इस मॉड्यूल का उपयोग करें।

Two tabs at the top of the page:पेज के ऊपर दो tabs हैं:

  • Master Wise Data — Delete specific master records for a selected module/group.चुने हुए module/group के खास master records हटाएं।
  • All Transaction without Master — Delete ALL transactional records while keeping master data.Master data रखते हुए सभी transactional records हटाएं।

Tab 1 — Delete Master DataTab 1 — Master Data हटाना

  1. Select Module Name and (if needed) Sub Module Name.Module Name और (जरूरत हो तो) Sub Module Name चुनें।

  2. Click Delete Master Data.Delete Master Data पर क्लिक करें।

  3. If records are in use by transactions, a warning modal lists each area. A Delete Unused button may appear for records not referenced anywhere.अगर records किसी transaction में उपयोग में हैं, तो warning modal हर क्षेत्र दिखाएगा। जो records कहीं use नहीं हो रहे उनके लिए Delete Unused बटन दिख सकता है।

  4. If records are not in use, an authentication modal appears. Enter Username, Password, and Reason. Click Confirm Delete.अगर records उपयोग में नहीं हैं, तो authentication modal आएगा। Username, Password और Reason डालें। Confirm Delete पर क्लिक करें।

Tab 2 — Delete All TransactionsTab 2 — सभी Transactions हटाना

Extreme Cautionअत्यधिक सावधानी
This deletes ALL transactional records from the entire system. Requires 3 CAPTCHA steps + credentials. Always take a database backup first. यह पूरे सिस्टम के सभी transactional records हटाता है। 3 CAPTCHA steps + credentials जरूरी हैं। पहले database backup जरूर लें।

  1. Click Delete All Transactions.Delete All Transactions पर क्लिक करें।

  2. CAPTCHA 1/3: Solve the math question and click Next, or No, Cancel to abort.CAPTCHA 1/3: गणित का सवाल हल करें और Next दबाएं, या रद्द करने के लिए No, Cancel।

  3. CAPTCHA 2/3 and 3/3: Solve each and click Next.CAPTCHA 2/3 और 3/3: हर एक हल करें और Next दबाएं।

  4. Security Verification: Enter Username, Password, Reason. Click Authorize & Clear Data.Security Verification: Username, Password, Reason डालें। Authorize & Clear Data पर क्लिक करें।

  5. A progress bar shows deletion in progress (% complete, table count). Do not close the browser.एक progress bar deletion की प्रगति दिखाएगा (% पूर्ण, table count)। Browser बंद न करें।

Chapter 12अध्याय 12

Best Practicesसर्वोत्तम तरीके

Excel File PreparationExcel फ़ाइल तैयार करना

  • Always save files as .xlsx (Excel Workbook). File → Save As → Excel Workbook (.xlsx).फ़ाइलें हमेशा .xlsx (Excel Workbook) में सेव करें। File → Save As → Excel Workbook (.xlsx)।
  • File name must exactly match the group name (e.g., Clients.xlsx for "Clients" group).फ़ाइल का नाम group के नाम से बिल्कुल मेल खाना चाहिए (जैसे "Clients" group के लिए Clients.xlsx)।
  • No extra sheets, charts, or images — keep files as plain data tables.कोई extra sheet, chart या image न हो — फ़ाइलें सादे data tables में रखें।
  • Remove all blank rows at the end of your data before uploading.Upload से पहले डेटा के अंत की सभी खाली rows हटाएं।

Before Any Deletionकिसी भी Deletion से पहले

  • Always take a database backup first. Use Export before any deletion.पहले हमेशा database backup लें। किसी भी deletion से पहले Export का उपयोग करें।
  • Get written authorisation from a manager.Manager से लिखित अनुमति लें।
  • Record date, time, reason, and your name for every deletion.हर deletion के लिए दिनांक, समय, कारण और अपना नाम नोट करें।
