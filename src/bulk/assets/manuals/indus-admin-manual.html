Indus Admin User Manual

इंडस एडमिन उपयोगकर्ता मैनुअल

Complete guide to managing clients, plans, modules, and subscriptions in the ExcelJet Admin Portal. Designed for Indus admins — no technical knowledge required.

ExcelJet एडमिन पोर्टल में क्लाइंट, प्लान, मॉड्यूल और सदस्यता प्रबंधित करने की पूरी गाइड। इंडस एडमिन के लिए बनाई गई — कोई तकनीकी ज्ञान आवश्यक नहीं।

🏢
Ch 1

Introduction — What is the Indus Admin Portal?

परिचय — इंडस एडमिन पोर्टल क्या है?

The Indus Admin Portal is a special section of ExcelJet that only Indus administrators can access. It is used to:

  • Register and manage client companies (who use ExcelJet)
  • Set up client databases and configure their login credentials
  • Control which modules/features each client can access
  • Manage subscription plans for different features
  • Assign Sahay (AI assistant) and Email feature subscriptions
  • Manage module groups that can be applied across multiple clients

How to Access

Open the ExcelJet app → On the Company Login screen, select "Indus" as the login type → Enter your Indus admin username and password → You will land on the Company Subscription page automatically.

ℹ️ Note: Indus admin accounts cannot access the regular client dashboard. They only see the 4 pages in the left sidebar.

Sidebar Pages Available

📋 Company SubscriptionMain page — manage all client records
💳 Manage PlansCreate and edit subscription plan catalog
🤖 Sahay & Email SubscriptionsAssign AI and email features to clients
🔧 Module Group AuthorityManage reusable module group templates

इंडस एडमिन पोर्टल ExcelJet का एक विशेष हिस्सा है जो केवल इंडस प्रशासक उपयोग कर सकते हैं। इसका उपयोग किया जाता है:

  • क्लाइंट कंपनियों को रजिस्टर और प्रबंधित करने के लिए
  • क्लाइंट डेटाबेस सेट करने और लॉगिन क्रेडेंशियल कॉन्फ़िगर करने के लिए
  • प्रत्येक क्लाइंट के लिए मॉड्यूल/फीचर नियंत्रित करने के लिए
  • विभिन्न फीचर के लिए सदस्यता प्लान प्रबंधित करने के लिए
  • सहाय (AI सहायक) और ईमेल सदस्यता असाइन करने के लिए
  • कई क्लाइंटों पर लागू होने वाले मॉड्यूल ग्रुप प्रबंधित करने के लिए

कैसे एक्सेस करें

ExcelJet ऐप खोलें → Company Login स्क्रीन पर "Indus" लॉगिन प्रकार चुनें → अपना इंडस एडमिन यूज़रनेम और पासवर्ड दर्ज करें → आप स्वचालित रूप से Company Subscription पृष्ठ पर पहुंचेंगे।

ℹ️ नोट: इंडस एडमिन अकाउंट नियमित क्लाइंट डैशबोर्ड एक्सेस नहीं कर सकते। वे केवल बाईं साइडबार के 4 पृष्ठ देखते हैं।

Edit Subscription — Tab 2: Module Settings

टैब 2: मॉड्यूल सेटिंग्स

This tab controls which modules (pages/features) are enabled or disabled for the client. A stats bar at the top shows how many modules are currently active (e.g., "12 / 25 enabled").

Module Grid

ColumnDescription
Module Head NameThe category/group this module belongs to (e.g., Masters, Reports)
Module Display NameThe name of the module as it appears to the client
Status (checkbox)Tick to enable, untick to disable this module for the client. Click the header checkbox to toggle ALL visible rows at once.

How to Enable/Disable Modules

Tick or untick checkboxes for individual modules as needed.
To select all: Click the checkbox in the Status column header to toggle all filtered rows.
Click "Save Module" (bottom of modal). Only changed rows are sent to the server. If no changes were made, a "No Changes" message appears.

Copy As — Copy Module Settings to Another Client

The "Copy As" button copies this client's current module configuration to another client, overwriting their settings.

Click "Copy As" — a popup opens with a searchable list of all clients.
Search and select the target client you want to copy to.
Click "Save". If the target client already has modules set up, a confirmation popup appears with a math CAPTCHA (e.g., "43 − 7 = ?"). Solve it correctly and click "Yes, Continue" to overwrite.
⚠️ Important: Copying modules OVERWRITES the target client's existing module settings. This cannot be undone. Solve the CAPTCHA only if you are sure.

यह टैब नियंत्रित करता है कि क्लाइंट के लिए कौन से मॉड्यूल सक्षम या अक्षम हैं। स्टेटस बार दिखाता है कितने मॉड्यूल वर्तमान में सक्रिय हैं।

मॉड्यूल सक्षम/अक्षम करने का तरीका

  1. व्यक्तिगत मॉड्यूल के लिए चेकबॉक्स टिक/अनटिक करें
  2. सभी टॉगल करने के लिए Status कॉलम हेडर चेकबॉक्स पर क्लिक करें
  3. "Save Module" पर क्लिक करें — केवल बदली हुई पंक्तियाँ सर्वर को भेजी जाती हैं

Copy As — दूसरे क्लाइंट को कॉपी करें

"Copy As" बटन इस क्लाइंट की मॉड्यूल सेटिंग दूसरे क्लाइंट को ओवरराइट करके कॉपी करती है। अगर लक्ष्य क्लाइंट में पहले से मॉड्यूल हैं, तो CAPTCHA हल करके पुष्टि करें।

⚠️ महत्वपूर्ण: कॉपी करने से लक्ष्य क्लाइंट की मौजूदा मॉड्यूल सेटिंग्स ओवरराइट हो जाती हैं। यह पूर्ववत नहीं किया जा सकता।

टैब 3: मॉड्यूल ग्रुप अथॉरिटी

This tab lets you apply a pre-configured Module Group (a saved template of modules) to this client's account. Instead of enabling/disabling modules one by one, you select a group and apply it all at once.

Controls

How to Apply a Module Group to a Client

Select Application Name from the dropdown.
Select Module Group — the template you want to apply.
Click "Load Module" to see which modules are in this group.
Click "Apply to Client". If the client already has modules, a confirmation CAPTCHA appears (math subtraction). Solve it to confirm overwrite.
⚠️ Applying a module group REPLACES the client's current module settings. The CAPTCHA confirms you intend this.

Edit Subscription — Tab 5: Indus Tool Authority

टैब 5: इंडस टूल अथॉरिटी

This tab controls which sidebar pages of the Indus Admin Portal this client company's admin can see and access. Each module is shown as a checkbox card.

How It Works

  • Each card shows a Module Name and its Module Path (technical route)
  • Tick a checkbox to allow that module; untick to restrict it
  • If all checkboxes are left unchecked, the client can see all modules (no restriction)
ℹ️ Leaving all unchecked = full access. Only check boxes when you want to explicitly restrict to specific modules.
🔄 RefreshReload the module list
💾 SaveSave the selected module access permissions for this client

यह टैब नियंत्रित करता है कि इस क्लाइंट के एडमिन को इंडस एडमिन पोर्टल की कौन सी साइडबार पेज दिखेंगी।

  • प्रत्येक कार्ड में मॉड्यूल नाम और पथ दिखता है
  • चेकबॉक्स टिक = उस मॉड्यूल तक पहुंच की अनुमति
  • सभी चेकबॉक्स खाली = सभी मॉड्यूल दिखेंगे (कोई प्रतिबंध नहीं)
ℹ️ सभी अनचेक छोड़ें = पूरी पहुंच। केवल तब चेक करें जब विशिष्ट मॉड्यूल तक सीमित करना हो।
